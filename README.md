# LIFEpath

A responsive, local-first career exploration website. No install, account, or server is required.

## Open it

Open `index.html` in a modern browser. All interactive features run in the browser.

## Explore

- Choose a suggested career or drag it onto Map of Life. Search roles, skills, interests, and related words as you type. Tap topic tags to get started. When a term is outside the catalog, the app offers related paths and an open-ended exploration card.
- Add multiple paths, open Reality check for planning ranges and prerequisites, and tick off suggested milestones.
- Compare a lower-cost college, studying while working, or a career change in What if? The comparisons update immediately from the demo assumptions.
- Select a simple avatar or upload a profile photo using the pencil control on the illustration. The selected avatar/photo is saved in this browser on this device.
- Toggle English/Hindi beside the theme button. Theme follows your device by default; the button cycles light, dark, and system.
- Save your map in this browser or download a JSON copy.

## About search and numbers

Search is instant and keyword-based across the built-in career catalog and related terms. It runs locally and does not fetch live job listings or salary data. Costs, timelines, and earnings are illustrative India-focused demo assumptions, not verified current tuition or salary data. Verify requirements, fees, and local pay before making decisions.
